# Prompt 06 — Public website implementation

Implement only the approved public-website plan. Read `AGENTS.md`, `product-spec.md`, and `mvp-boundaries.md` first.

Required navigation:
- Servixo logo, Home, Services, Premium Plans, How It Works, Login, Become a Professional.

Required homepage sections:
- Hero, How It Works, Services, Premium Plans, FAQ, CTA, Footer.

Other required capabilities:
- PIN-code availability checker.
- Customer signup/login entry points.
- Professional registration entry point.
- Responsive mobile-friendly layout.
- Contact and basic company information.

Use existing design system, brand assets, routing, and component conventions. Do not invent actual prices, service coverage, testimonials, guarantees, contact details, or company/legal claims. Use approved content or clearly marked content placeholders. Make serviceability results derive from backend data; do not hard-code PIN code availability.

Do not add checkout/e-commerce or excluded AI voice/chat booking features unless separately approved. Include accessible labels, keyboard behavior, semantic headings, responsive states, and loading/error/empty states.

Before editing, confirm the approved plan and list files to change. After implementation, run relevant checks and report exact results.
