# Prompt 01 — Plan one Servixo feature (no implementation)

Read `AGENTS.md` and the relevant Servixo product/business/architecture documentation. Inspect the existing implementation before proposing changes.

Feature to plan: [DESCRIBE ONE FEATURE]
Primary role: [CUSTOMER / PROFESSIONAL / ADMIN / PUBLIC / BACKEND]

Do not edit files. Produce a detailed implementation plan containing:
1. User story and business outcome.
2. Requirements from Servixo documentation that apply.
3. Existing code paths and reusable components/services.
4. Role and ownership permission matrix.
5. Data/schema changes and migration/backward-compatibility impact.
6. API contracts, validation, authorization, and error cases.
7. UI pages/components and loading/empty/error states.
8. State transitions and transaction/idempotency requirements.
9. Security, privacy, and audit requirements.
10. Edge cases and concurrency risks.
11. Test plan: unit, integration, and E2E.
12. Acceptance criteria.
13. Open product decisions and assumptions.
14. Small implementation tasks in dependency order.

Do not invent missing financial, subscription, visit, cancellation, refund, payout, or slot rules. Flag those as blockers or explicit assumptions. Stop for review and approval before coding.
